# Community Food Share Platform

# 📌 Project Description

The Community Food Share Platform is a full-stack web application developed to support Sustainable Development Goal (SDG) 2: Zero Hunger. The platform helps connect people and organizations with surplus food to those in need, reducing food waste and promoting social welfare.
Users can add food donation details such as donor name, food item, quantity, location, and contact information. The application stores this data in a MongoDB database and allows users to perform complete CRUD (Create, Read, Update, Delete) operations through a simple and user-friendly interface.
This project is built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB, demonstrating the integration of frontend, backend, and database technologies in a real-world application.

# 📂 Project Objective

The main objective of this project is to reduce food wastage by creating a platform where surplus food can be donated and distributed to people in need. The application also serves as a practical example of full-stack web development and database management.


# 🔄 CRUD Operations

Create: Add new food donations
Read: View all available donations
Update: Edit donation information
Delete: Remove completed or expired donations
